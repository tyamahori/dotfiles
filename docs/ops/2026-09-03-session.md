## Claude Code 設定案の検討（未適用）

ユーザー案 `{advisorModel: "fable", permissions.defaultMode: "auto", viewMode: "focus"}` を
公式 docs（settings-reference / advisor）と `claude/settings.json` で突合した。

- `permissions.defaultMode: "auto"` は `claude/settings.json:410` に設定済みで変化なし。
- `viewMode: "focus"` は表示のみの変更（直前プロンプト・ツール 1 行要約・最終応答）。
  fullscreen renderer 前提だが settings に `tui` 指定はなく、起動確認が必要。導入は問題なし。
- `advisorModel: "fable"` は quota リスクあり: advisor は呼ばれるたびに会話全体を
  非キャッシュで再読し（200k context なら 1 回 Fable 200k input 相当）、回数上限なし、
  subagent も継承。main が `claude-fable-5-1` なので許可される advisor は Fable 5.1 のみ。
  Fable の usage-credits consent 未了なら `/model fable` で承諾しないと無効。
- 提案: `viewMode` は常設、`advisorModel` は常設せず長い refactor / debug のセッションで
  `claude --advisor fable` か `/advisor fable` を一時利用し `/usage` で消費を見てから判断。
