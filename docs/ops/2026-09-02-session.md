## ブラウザ検証経路の整理(browser-verify skill)

- terminal-browser のもっさり感を受けて経路を再決定。人が見る必要があるかで選ぶ:
  エージェントだけ→headless(OMP `browser` ツール)、人が見る→使い捨て `--user-data-dir` の
  別窓 Chrome(リテラル `--guest` は自動化に制約があるので不採用)、ログイン済み→relay、
  terminal-browser は「ペインの横で見せて」と明示された時だけ。
- 別窓 Chrome で Google 検索「ひがふな」を実演し、滑らかさを確認して `kill` で閉じた。
- 手順を `agents/skills/browser-verify/SKILL.md` に集約(1スキル+モード別セクション、
  OMP / Claude Code / Codex 別レシピ)。`global-instructions.md` の節は判断ルールと
  スキルへのポインタだけに縮めた。
- headless は OMP 専用と割り切り、Claude Code / Codex は claude-in-chrome / Codex browser
  plugin に落とす。agent-browser 等の追加導入はしない(ユーザー決定)。
