# 2026-09-05 セッション

## エージェント向けツールの追加

omp / Claude Code / Codex をより活用するために抜けていたツールを、層ごとの正本へ追加して導入した。

- `scripts/devbox`: `delve`, `git-absorb`, `hyperfine`, `bash-language-server`, `yaml-language-server`, `typos`
- `.Brewfile`: `ffmpeg`（OMP `read` の動画対応に必要）
- `scripts/python`: `uv tool install --upgrade debugpy`

見送ったもの: yq（jaq で足りる）、just（go-task）、tmux（herdr）、delta / difftastic（hunk）、Playwright MCP（OMP browser + browser-verify）、context7 系 MCP（ツール定義の常駐コストに見合う困りごとがない）。

### 確認したこと

- 新規セッションの `lsp status` に `bashls` と `yamlls` が加わった（現セッションは PATH 検出が起動時固定で `reload` では出ない）。
- OMP `debug` ツールで debugpy の launch → breakpoint → continue → evaluate → terminate が動作した。

### 直した問題

OMP built-in の debugpy 定義は `python -m debugpy.adapter` を起動するが、uv tool は隔離 venv なので既定の python から import できず `DAP connection closed` で失敗した。
`omp/dap.json` で `debugpy-adapter` 実行ファイルへ差し替え、`scripts/link` で `~/.omp/agent/dap.json` へリンクした。
`pre-commit-json` の canonical 対象と README、`docs/omp.md` にも反映した。
