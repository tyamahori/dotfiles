# 2026-09-05 セッション

## エージェント向けツールの追加

omp / Claude Code / Codex をより活用するために抜けていたツールを、層ごとの正本へ追加して導入した。

- `scripts/devbox`: `delve`, `git-absorb`, `hyperfine`, `bash-language-server`, `yaml-language-server`, `typos`
- `.Brewfile`: `ffmpeg`（OMP `read` の動画対応に必要）
- `scripts/python`: `uv tool install --upgrade debugpy`

見送ったもの: yq（jaq で足りる）、just（go-task）、tmux（herdr）、delta / difftastic（hunk）、Playwright MCP（OMP browser + browser-verify）、context7 系 MCP（ツール定義の常駐コストに見合う困りごとがない）。

### 確認したこと

- 新規セッションの `lsp status` に `bashls` と `yamlls` が加わった（現セッションは PATH 検出が起動時固定で `reload` では出ない）。
- OMP `debug` ツールで debugpy の launch → breakpoint → continue → evaluate → terminate が動作した。

### 直した問題

OMP built-in の debugpy 定義は `python -m debugpy.adapter` を起動するが、uv tool は隔離 venv なので既定の python から import できず `DAP connection closed` で失敗した。
`omp/dap.json` で `debugpy-adapter` 実行ファイルへ差し替え、`scripts/link` で `~/.omp/agent/dap.json` へリンクした。
`pre-commit-json` の canonical 対象と README、`docs/omp.md` にも反映した。

## GPT-6 Astra への切り替え

OpenAI の [latest-model ガイド](https://developers.openai.com/api/docs/guides/latest-model) を読み、モデル設定と共通プロンプトを見直した。
omp 18.1.10 も Codex CLI 0.153.2 も `gpt-6-astra` を認識済み。
一方で `gpt-5.4` は omp の registry から消えており、fallback chain の 2 段目は死んでいた。

- `omp/config.yml`: `plan` / `slow` と reviewer 系の override を `gpt-6-astra` へ。`task` / `advisor` / `vision` は量が多いので `gpt-5.6-terra` のまま。Anthropic 側の fallback は `gpt-6-astra` → `gpt-5.6-sol`（`anthropic-usage-guard.ts` と `APPEND_SYSTEM.md` も同期）。
- `codex/config.toml`: system 層の既定を `gpt-6-astra`、effort は移行ガイドどおり現行の `low` を維持。user 層（`~/.codex/config.toml`）は `/model` で既に astra / medium になっており、そちらが勝つ。
- `agents/global-instructions.md`: Astra の癖への対処を 3 点だけ追加。ユーザー指示が skill / AGENTS.md より優先し、skill が原因で止まったら SKILL.md と該当行を示す。散文優先で常套句を避ける。検証は変更に必要な分を一度だけ。

動作確認は最小プロンプトで済ませた。
omp は `--model openai-codex/gpt-6-astra`、Codex は `codex exec` の `model: gpt-6-astra` 表示で応答を確認した。

見送りは 2 件。
`task` 役割の astra 化は週次枠への影響を数日分見てから判断する。
ガイドが強く推奨する skill 群の指示監査は `omp-learning-loop` の枠で別途行う。
